# mixed-estate-001 — real Transform assessment (12-server estate)

`business_case.md` generated by `tools/transform_ingest.py::load_business_case` from an actual AWS
Transform console export (`Initial_Migration_Assessment_20260902_161429.zip` — PPTX + XLSX + PDF).
This is the **same estate** as [`../discovery-001/`](../discovery-001/): the discovery export is the
input you upload; this is Transform's assessment output.

## What Transform says

- **12 servers** (10 Linux, 2 Windows), all right-sized to **`c5a.large`** (2 vCPU / 4 GiB, x86);
  the two Windows boxes go to `c7i-flex.large` at 3-Year RI. Right-sized on peak (avg 90% CPU).
- **11 EBS GP3 volumes** (498 GiB provisioned, 17.4% used - boot-dominated) + **1 FSx for NetApp
  ONTAP** device (the `nfs-01` box).
- Region **us-east-1**, x86, Shared tenancy, Single-AZ. Recommended pricing: **3-Year RI**.
- Cost basis (compute + network + storage, from the PDF Financial Summary, excl. AWS Business
  Support): on-demand **$968/mo**, 1yr RI **$727/mo**, 3yr RI **$586.50/mo** (all-in with support
  ~$645/mo). On-prem ~$2,719/mo.
- **Assessment issue on every server:** "vCPU specification missing or invalid - using default 2
  vCPUs; cost estimates may be inaccurate." The whole sizing is **provisional** until the inventory
  carries real CPU core counts - hence `budget.basis = "transform_3yr_ri_provisional"`.

## Contract notes

- `c1 sizing_basis = peak_with_headroom` — Transform right-sized on peak (avg 90% CPU is high).
- `c2 out_of_scope` on **EC2AMAZ-HVB61P6** — pinned at 100% CPU with no identifiable workload
  (from the paired discovery export); any action on it is denied until it's identified.
- No ARM / `modernization_unsupported` constraints — a wave with `WaveInputs(modernization_target=
  "container")` will *generate* the container IaC artifact (verified, not applied); the databases
  (Oracle XE, SQL Server) and Windows boxes stay on the rehost path.
- Application and dependency detail (which service talks to which DB, Redis, Jenkins, etc.) is **not
  in a Transform assessment** — it's in the discovery export. See `../discovery-001/`.
